How stacks work in this application

Push: Adds a page to a stack.

Pop: Removes the most recent page from a stack.

LIFO: Last In, First Out. The last page stored is the first page retrieved.

Back: Moves the current page to the Forward Stack and retrieves the last page from the Back Stack.

Forward: Moves the current page to the Back Stack and retrieves the last page from the Forward Stack.
